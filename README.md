# Weather Frontend

A basic React application for displaying data from a REST API.

## Setup

Install dependencies:
```bash
npm install
```

## Development

Start the development server:
```bash
npm run dev
```

The application will be available at `http://localhost:5173`

## API Configuration

By default, the application makes API calls to `http://localhost:3000/api/data`. You can modify the API endpoint in `src/App.jsx`.

## Build

Create a production build:
```bash
npm run build
```

Preview the production build:
```bash
npm run preview
```
